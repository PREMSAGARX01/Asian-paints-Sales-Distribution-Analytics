# *Asian Paints – Sales & Distribution Analytics*

An interactive business intelligence dashboard developed using Microsoft Power BI to analyze sales, regional performance, products, dealers, inventory and marketing expenditure.

### Project Overview

The project consists of seven dashboard pages, combining key performance indicators, interactive charts, DAX measures and slicers to explore business performance.
